A satin ribbon of plasma whips across a violet void, twists edge-on, and ignites a blazing knot
where it crosses itself, throwing embers and a shock-ring past a tiny figure on the ridge below.
Drawn entirely by code: pure Python 3.13 standard library, no image assets, no libraries.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024, under 1 MiB). Outside the grader's container:
`mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`.
